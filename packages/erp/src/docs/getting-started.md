# Bắt đầu với Frezo ERP

Chào mừng bạn đến **Frezo** — hệ thống ERP nội bộ.

## Đăng nhập & điều hướng

1. Đăng nhập bằng tài khoản được cấp.
2. Sidebar bên trái liệt kê các module theo quyền (menu từ BE).
3. Dùng **Ctrl+K** (Command Palette) để tìm trang nhanh.
4. Chuông thông báo → deep-link tới ticket, nghỉ phép, PR, v.v.

## Module chính

| Module | Path | Mô tả ngắn |
|--------|------|------------|
| Dashboard | `/` | Tổng quan KPI & thao tác nhanh |
| Nhân sự (QLNS) | `/qlns/*` | Nhân sự, lương, nghỉ, tuyển dụng |
| Kế toán | `/accounting/*` | Sổ cái, trial balance, BCTC |
| Kho | `/warehouse/*` | Reorder, stock alert, PR/PO |
| CRM | `/crm/*` | Lead, deal, invoice |
| Phê duyệt | `/approval/inbox` | Inbox approval đa loại |
