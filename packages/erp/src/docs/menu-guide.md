# Hướng dẫn menu bên trái

Menu bên trái giúp bạn chuyển giữa các phần việc trong Frezo. Mỗi người chỉ thấy những mục mình được phép dùng.

## Cách dùng sidebar

1. Nhìn cột bên trái — các **nhóm cha** (Nhân sự, Kế toán, Tài sản…).
2. Bấm **nhóm cha** để mở / thu danh sách trang con.
3. Bấm tên trang con để mở màn hình đó.
4. Khi đang ở một trang, nhóm cha sẽ **mở sẵn** và được tô sáng để bạn biết mình đang ở đâu.
5. Muốn gọn màn hình: bấm mũi tên thu sidebar — lúc này chỉ còn icon; rê chuột vào icon để xem tên.

**Kết quả:** Bạn tìm được đúng trang bằng tên tiếng Việt trên menu, không cần nhớ đường dẫn.

## Các nhóm thường gặp

| Nhóm trên menu | Dùng để |
|----------------|---------|
| **Dashboard** | Tổng quan nhanh |
| **Nhân sự** | Hồ sơ, lương, nghỉ phép, chấm công… |
| **Kế toán** | Sổ cái, báo cáo tài chính |
| **Kho** | Nhập xuất, cảnh báo tồn |
| **CRM** | Khách hàng tiềm năng, hợp đồng bán |
| **Phê duyệt** | **Hộp thư duyệt** và cấu hình luồng duyệt |
| **Công việc** | Ticket / việc cần làm |
| **Tài sản** | Quản lý tài sản, khấu hao |
| **Khách hàng** | Danh sách khách hàng |
| **Quản trị hệ thống** | Người dùng, vai trò, cài đặt (thường Admin) |
| **Tài liệu** | Hướng dẫn dùng Frezo (đúng nơi bạn đang đọc) |

## Mở trung tâm hướng dẫn

1. Vào **Dashboard**, hoặc nhìn cuối sidebar.
2. Bấm **Tài liệu**.
3. Chọn bài theo việc bạn cần làm (duyệt đơn, tài sản, khấu hao…).

**Kết quả:** Danh sách hướng dẫn bằng tiếng đời thường — chọn bài phù hợp rồi làm theo từng bước số.

## Không thấy một mục?

**Lưu ý:** Chỉ tài khoản Admin (hoặc vai trò được cấp quyền cấu hình) mới thấy một số mục **Quản trị hệ thống**.

Nếu thiếu menu nghiệp vụ hàng ngày → liên hệ Admin để được gán đúng vai trò.
